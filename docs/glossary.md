# Glossary

Portuguese terms appear in the UI and in the current database; English terms
are used in code and in these documents.

| Portuguese (UI / database) | English (code / docs) | Meaning |
|---|---|---|
| Banco de questões | Question bank | One SQLite `.db` file holding the questions of one discipline |
| Disciplina | Discipline | A named link to a question bank file (e.g. "Biologia") |
| Questão (`questoes`) | Question | One item that can be placed in an exam |
| Enunciado | Statement | The rich-text prompt of a question |
| Alternativa | Alternative | One of the options of a multiple-choice question |
| Gabarito | Answer key | The correct letter, or the expected answer of an essay question |
| Múltipla Escolha | Multiple choice | Question type with alternatives A–E |
| Dissertativa | Essay | Open-answer question type |
| Categoria / Assunto (`assuntos`) | Category | A node in the topic tree used to classify questions |
| Dificuldade: Fácil, Médio, Difícil | Difficulty: easy, medium, hard | |
| Segmento | Segment | School stage: "Ensino Fundamental" or "Ensino Médio" |
| Ano / Série (`ano_sugerido`) | School year | Grade the question is suited for: 6º–9º Ano, 1ª–3ª Série |
| Fonte da questão (`fonte_questao`) | Source | Where the question came from (ENEM, FUVEST, a book) |
| Ano de origem (`ano_origem`) | Source year | Year the question was published or applied; unrelated to school year |
| Prova | Exam | A Word document generated from selected questions |
| Versão | Version | One of several shuffled variants of the same exam |
| Selecionar | Select | Mark a question for inclusion in the exam being built |
