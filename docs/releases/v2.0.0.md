# Prometheus 2.0.0 release preparation

**Updated:** 2026-11-19

Version 2.0.0 includes the implemented work in specs 001–017. The owner
subsequently authorized the macOS build, which is prepared for Apple Silicon
on macOS 15.0 or newer with ad-hoc signing. Windows 2.0.0 has not been built.
GitHub publication and the `v2.0.0` release tag remain pending.

Use the [Portuguese public release notes](v2.0.0-notes.md) as the release body
and the [publishing guide](publishing.md) for the exact local files to attach.

## Included changes

- Versioned, backup-protected bank upgrades with explicit reporting of unmapped
  legacy values. Schema 6 includes normalized questions/categories, classes,
  saved exams, generated arrangements and usage records.
- Question editing/duplication, relational category management and multiple
  choice with two to five alternatives.
- Accent-insensitive visible-text search, category descendants, pagination,
  source-year ranges and selection preserved across pages/filters.
- Saved exams, class selection, usage history and regeneration that retains
  compatible arrangements while using current content and correct answers.
- Compact question cards, on-demand history, visible preview resizing and
  a guarded fresh-exam action.
- Word export with images, chosen order, labelled versions and matching keys.
- Dark-theme surface fixes, resizable help, revised help/legal text and the
  supplied official icon.
- Compact drag-to-Applications DMG, consistent Finder version/identity and
  declared macOS 15.0 minimum.
- Packaging corrections for post-signing FinderInfo metadata and python-docx
  paths that need a physical `docx/parts` directory to load footer templates.

## Bank compatibility

The app makes an automatic backup before a bank upgrade. Older banks requiring
normalization receive a warning and a report of values needing review. Do not
open an upgraded bank with an older executable. Keep bank files and backups
outside the repository.

The supplied biology-bank acceptance compared all 2,597 original questions,
exam/answer-key structures and embedded images. See the
[005 acceptance report](../../specs/005-schema-normalization/acceptance.md).
During macOS testing, the owner's intervening schema-3-to-6 upgrade was audited
against its automatic backup; the legacy question/category rows were preserved.
