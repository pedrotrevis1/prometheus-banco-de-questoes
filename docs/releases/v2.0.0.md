# Prometheus 2.0.0 source preparation

**Date:** 2026-11-18

This change prepares the complete 005/006 implementation and review fixes for
version 2.0.0. The owner explicitly excluded building the apps from this task.
Windows and macOS binaries, packaged-app acceptance, release publication and
the final release tag remain pending. A version number in source does not mean
that a new executable has been published.

## Included changes

- Versioned, backup-protected bank upgrades with explicit reporting of unmapped
  legacy values. Schema version 6 includes normalized questions/categories,
  managed classes, saved exams, generated arrangements and usage records.
- Question editing and duplication, relational category management, descendant
  category filtering, and multiple-choice questions with two to five options.
- Accent-insensitive search of visible question, alternative and expected-answer
  text, with pagination, persistent selection and source-year range filtering.
- Improved Word exam and answer-key output, image handling, teacher-chosen
  question order and labelled versions.
- Saved exams with a class, ordered questions and generation settings. Usage
  history appears on cards and supports never-used/not-used-since filters.
- Regeneration preserves compatible saved arrangements while using current
  question content and correct answers. Incompatible arrangements are blocked.
- Preview resizing now expands the containing card and reflows subsequent cards;
  the owner confirmed all 010 acceptance scenarios checked. See the
  [010 acceptance report](../../specs/010-preview-visible-resize/acceptance.md).
- Review fixes preserve class selection during control refreshes and retain
  saved arrangements across presentation changes and unsuccessful exports.

## Bank compatibility

Before upgrading an existing bank, the app makes an automatic backup. Older
banks requiring normalization receive an incompatibility warning and a report
of values that cannot be mapped safely. Do not open an upgraded bank in an
older executable. Keep personal bank files and backups outside the repository.

The supplied biology-bank acceptance compared all 2,597 original questions,
their generated exam/answer-key structures and embedded image bytes. The
owner also performed representative visual card and Word checks. See the
[005 acceptance report](../../specs/005-schema-normalization/acceptance.md).
